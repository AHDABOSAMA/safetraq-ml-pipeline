# Data Documentation

This directory contains small example CSV files and documentation for the SafeTraq data workflows.

## Directory Structure

- `sample/` — 12 example CSV files generated by the legacy synthetic-data generator.
- `raw/` — generated prototype data; excluded from Git.
- `processed/` — generated preprocessing outputs; excluded from Git.

The `raw/` and `processed/` directories may exist locally but are not tracked by this repository.

## Sample Data

The `sample/` directory contains two examples for each of six scenarios:

| Category | Scenarios |
|---|---|
| Crash | Frontal collision, side collision, vehicle rollover |
| Normal driving | Highway driving, hard braking, pothole impact |

These files are **synthetic examples** generated by the legacy prototype script. They must not be treated as real-world sensor recordings or as evidence of model performance on real road conditions.

## Legacy Prototype Data Generation

The scripts in `scripts/original/` belong to an earlier prototype and are not the implementation of the thesis pipeline.

The generator in `scripts/original/1_generate_data.py` creates 300 CSV files by default:

- 150 crash scenarios: frontal, side, and rollover.
- 150 normal-driving scenarios: highway, hard braking, and pothole impact.

It simulates accelerometer, gyroscope, GPS, timestamp, and label fields at a configured sampling rate of 100 Hz.

To regenerate the prototype data from the repository root, run:

```powershell
python scripts/original/1_generate_data.py
```

The generator writes CSV files to `data/raw/crashes/` and `data/raw/normal_driving/`. Running it again overwrites files with matching names.

The preprocessing script is also part of the legacy workflow. Review `scripts/original/README.md` and `scripts/original/2_preprocess_data.py` before running it.

## Thesis Pipeline and External Datasets

The thesis experiments are in `notebooks/01_data_pipeline_and_models.ipynb`. The notebook reads seven simulation datasets and a set of real driving sessions from Kaggle. None of them are stored in this repository.

| Kaggle dataset | Files | Source ID in the notebook |
|---|---|---|
| `youssefashraf57/crash-data` | `crash_data.csv`, `crash_data_log.csv`, `all_crash_data.csv` | PC1 |
| `youssefashraf57/crash-data1` | `all_crash_data1.csv`, `normal_driving_data.csv`, `highway_driving_data.csv`, `traffic_jam_data.csv` | PC2 |
| `youssefashraf57/real-data` | 23 real driving sessions: 6 driving-behaviour sessions (aggressive, standard, slow) and 17 road-anomaly sessions (9 speed bumps, 8 potholes) | Used only for the real-data test |

The seven simulation files are the crash, normal, highway and traffic-jam recordings from the two simulation machines. After cleaning, segmenting and windowing, they give 6,830 windows. The real sessions contain no crashes and are used only to measure false alarms.

## Version Control and Reproducibility

Generated files under `raw/` and `processed/` are excluded from Git to avoid committing large or reproducible artifacts. The small examples in `sample/` are retained to make the data format and scenario naming easier to inspect.

For reproducible experiments, document the source datasets, preprocessing steps, train/test split strategy, and random seeds used by the thesis pipeline.

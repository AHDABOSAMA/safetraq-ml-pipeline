# Legacy Prototype Scripts

These scripts are retained for historical reference from an earlier SafeTraq prototype.

They are **not the implementation of the thesis pipeline** documented in [`notebooks/01_data_pipeline_and_models.ipynb`](../../notebooks/01_data_pipeline_and_models.ipynb).

## Scripts

- `1_generate_data.py` — generates prototype data.
- `2_preprocess_data.py` — preprocesses the prototype data.
- `3_train_model.py` — trains the prototype model.
- `4_evaluate_model.py` — evaluates the prototype model.

## Important limitations

- The prototype uses a different data and modeling workflow from the notebook.
- Do not interpret its generated data as real-road sensor data.
- Review the scripts and their dependencies before running them.
- The notebook is the primary reference for the documented thesis experiments.

These files are preserved to maintain project history and are not presented as the current production or deployment pipeline.
